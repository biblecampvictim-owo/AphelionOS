Hello and thanks for checking out AphelionOS! A few things to note:

1 - This OS is only to be run on QEMU as of Nov 2. 2026. This, obviously, also makes QEMU necessary for running it. 
2 - It is highly recommended you emulate this OS on Linux - Based Operating Systems. As of Nov 2. 2026  I have no idea what happens if you try to emulate/virtualize this on Windows But i am working towards that being possible on Windows 11.
3 - To run it, Download the source code and run the "run.sh" file via your terminal (And of course give it permission to run).


Please note that this Operating System is not finished yet which means that ANYTHING is subject to change.
