Hello and thanks for checking out AphelionOS v1.4!

To run AphelionOS, check out HOWTORUN.md

What AphelionOS Version 1.4 added:
-
- a Heavily improved IDT
- Chess!
- Graphics
- Customisation on boot
- Rebooting
- Improved Musical Keyboard
- An ISO format
- You can now virtualise this on not just Linux but also: Windows / MacOS / Any OS with virtualization support with the new ISO format



Fixes:
- Fixed cursor at weird position bug
- Fixed some background colours not working

Please note that this Operating System is not finished yet which means that ANYTHING is subject to change.
